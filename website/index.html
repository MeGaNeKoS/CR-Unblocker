Version 4.1.1 Release

Thank you for using CR-Unblocker! The free community proxy runs on spare capacity of my personal server, and it is past its limit. In September it handled over 450,000 connections from more than 15,000 different IP addresses, with peaks above 40,000 a day. About 10% of that was not Crunchyroll at all: someone appears to have put our login on their whole network, sending DNS lookups and sites like YouTube, X and Instagram through it. The server now refuses anything that is not Crunchyroll. In the first week of October alone it moved over 60 GB.

I started the community proxy because I had spare resources on my server and was happy to share them for free. It has also been a good opportunity for me to learn network management. But it now uses far more resources than I had or ever expected, and I have no plans to add more servers or upgrade the current one.

The community proxy is meant for watching anime and has been optimized for that, so the bandwidth limit is now enforced: each IP gets 500 MB per month at full speed, up to 5 GB per month. As a heavy otaku living in Japan myself, 500 MB is enough for me to watch every new series each month, since video does not go through the proxy by default. Reading manga is different: it needs the "Proxy static assets" option, which sends every page image through the proxy. If you read manga, I advise you to get your own proxy. You can still use the community proxy for up to 5 GB a month, but past 500 MB the speed is not guaranteed.

For a faster, more reliable connection with no limit, use your own proxy. A private US proxy with its own IP costs around $10 a year; enter it on the addon's Settings page under "Use custom proxy".

To route your traffic and apply the bandwidth limit, the server sees your IP address and the Crunchyroll host you connect to. It only stores weekly and monthly aggregate data, kept for the last two months, for stability metrics and abuse prevention.

Changelog

4.1.1: Quieter proxy notifications and community proxy notice

  • Added a community proxy notice to the popup and settings
  • Proxy error notifications appear once after five consecutive errors
  • Errors during proxy tests no longer trigger notifications
  • Any successful proxied request resets the error count

4.1.0 – Local diagnostics and traffic controls

  • Added structured local request diagnostics with Error, Warning, Info, Debug, and Trace levels
  • Added controls for proxying static assets and media/video traffic
  • Kept static assets and media/video direct by default to reduce proxy bandwidth usage
  • Improved settings layout and removed credential-bearing debug output

4.0.3 – Firefox context fix and policy update

  • Updated the service monitor link to the correct endpoint
  • Linked directly to the HAProxy statistics dashboard for detailed status checks

4.0.0 – Major update and new proxy server

  • Switched default proxy server to us.community-proxy.meganeko.dev
  • Now proxies only geo-restricted Crunchyroll traffic, direct for all other traffic
  • No more session ID manipulation—unblocks anime directly
  • Improved support for all regions, including Japan

3.2.0 – New default proxy and improved access for restricted regions

This release changed the default proxy and improved proxy handling.

  • Changed default proxy endpoint
  • Reduced load on proxy availability check
  • Proxied initial website load to allow access from restricted regions like Japan

Added support for HTTP proxies and UI improvements with proxy availability checks.
